# MaxAI

Proyecto Android (WebView) generado desde tu HTML.

## Compilar
- GitHub: sube todo a un repositorio; Actions > Build APK > descarga el artefacto app-debug-apk.
- Android Studio: File > Open, luego Build > Build APK(s).

Tu HTML esta en app/src/main/assets/www/index.html. Puedes editarlo ahi y recompilar.
Puente Java disponible desde JS: objeto Android (toast, vibrate, flashlight, share, copy, openUrl, call, sms, showNotification, keepScreenOn, setBrightness, deviceInfo, battery, getLocation, hasPermission, requestPermission, exit).
